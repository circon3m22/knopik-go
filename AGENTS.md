# Knopik GO

Самостоятельная восьмибитная игра. Репозиторий — circon3m22/knopik-go, основная ветка main. Локальная разработка — npm run dev, http://127.0.0.1:3000/.

Вся игровая графика должна оставаться SVG/CSS, звук — процедурным Web Audio. Не добавлять переключатель на оригинальное оформление. Knopik TAP — отдельная сохранённая игра; не менять её репозиторий или исходники при работе над GO.

Прогресс GO записывается только в таблицы Supabase с префиксом knopik_go_. Учётные записи и роли общие с TAP. Таблица game_saves доступна здесь только для первоначального чтения и переноса, если запись GO ещё отсутствует.

Пользователь разрешил первоначальный перенос кода в этот репозиторий. Это не разрешение на публикацию сайта. До нового указания продолжать разработку локально.

Последнее указание по проверкам — «пока не тестируй, продолжай работу». Не запускать тесты или игровые сценарии, пока пользователь не изменит ограничение. Локальную игру можно открывать для наблюдения.

Не включать в коммиты зависимости, сборки, рабочие временные файлы, локальные сохранения и секреты. Публичный клиентский ключ Supabase не является серверным секретом.
