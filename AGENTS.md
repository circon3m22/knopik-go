## Этап 9 — постоянные GPU-буферы и подготовка старта (2026-10-13)

У прозрачных слоёв WebGL повторно выделялась память при каждом изменении обрезанного прямоугольника, включая несколько слоёв одного кадра. Теперь сначала определяются максимальные размеры слоёв на каждой глубине, затем сохраняется ёмкость одного буфера на глубину. Изменение обрезки использует viewport/scissor и масштаб UV; проверка framebuffer выполняется только при реальном выделении. При повороте/resize старые ёмкости освобождаются, чтобы не удерживать квадрат из двух ориентаций. Видимый кадр сохраняет полный DPR, сглаживание, порядок и прозрачность.

Fallback-пути за экраном отсекаются до создания Canvas/текстуры. Нулевые коллинеарные выступы ступенчатых крыш исключаются только из триангуляции заливки; исходный контур обводки остаётся полным. Старые версии растровых путей, изменившихся вслед за камерой, освобождаются после показа кадра, когда больше не используются. Они перестают забивать кеш неизменяемых спрайтов.
