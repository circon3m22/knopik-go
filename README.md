# Knopik GO

Самостоятельная восьмибитная игра на основе механик Knopik TAP. TAP сохранён отдельно; в GO нет переключения на его оформление.

## Локальный запуск

Node.js 22.13 или новее. Установить зависимости командой `npm ci`, затем `npm run dev`. GO открывается на http://127.0.0.1:3000/. В рабочем окружении зависимости пока подключены через junction к ранее установленному node_modules; исходники и сборка GO находятся в собственной папке.

Репозиторий: [circon3m22/knopik-go](https://github.com/circon3m22/knopik-go), основная ветка `main`.

Для сборки: `npm run build`. Для запуска собранной версии: `npm start`. Публикация сайта пока не настроена.

## Игра

Главный экран — кликер Кнопика. Напитки на полке открывают игры и дают эффекты. Сохранены темп, эмоции, усталость, ультра-тап, сейф, задания, кейсы, магазин, одежда и настройки. «Лайм» проверяет точность, «Матча» — память; также доступны барабаны, мины и риск.

Напитки покупаются из активного баланса на главном экране. Одежда и фоны продаются за монеты из сейфа. Перенос в сейф запускается свайпом слева направо.

Вся игровая графика — SVG и CSS. Пиксельные эффекты имеют ограниченное число частиц; статические SVG-компоненты мемоизированы. Звук создаётся Web Audio: квадратные и треугольные волны, ступенчатые ноты, дискретный шум. Шрифт Tiny5 с кириллицей поставляется локально с лицензией OFL. PNG нужны только для значков установки PWA и превью ссылки; они экспортируются из SVG-кода командой `node scripts/export-pixel-icons.mjs`.

## Аккаунты и прогресс

Supabase: `uxxzvjwsexdoqcevzipu`. Аккаунты общие, Фома остаётся администратором. Смена пароля в интерфейсе отсутствует.

GO использует `knopik_go_saves`, `knopik_go_config`, `knopik_go_promo_codes` и RPC `redeem_knopik_go_promo_code`. Локальное сохранение — `knopik-go:save:<userId>`. Существующие таблицы TAP не меняются.

При первом входе, если сохранения GO ещё нет, текущий прогресс переносится из прежнего облачного сохранения в новую запись GO. После этого запись, настройки сложности и промокоды независимы. SQL применён через Supabase MCP; его копия находится в `docs/separate-go-schema.sql`. Не запускать этот SQL повторно как новую миграцию.

## Текущий статус

Разделение выполнено 11 октября 2026 года. GO — рабочий проект, TAP — сохранённая опубликованная версия `076db62`. Последний локальный коммит исходного репозитория `23f8f27` также сохранён отдельным архивом.

По просьбе пользователя тесты, сборка для публикации и мобильные проверки отложены. Тесты игровых движков сохранены для следующего этапа. Полноценный запуск PWA без интернета, включая загрузку аккаунта и последующую синхронизацию, требует отдельной доработки.
