# ARCADE UPDATE 0.3.0: оранжевый анонс и тапалка

По прямому указанию пользователя номер этого выпуска остаётся 0.3.0. Недавние публичные записи 0.3.1 и 0.3.2 объединены с ним; прежняя история 0.2.x сохранена. Формат сохранения34 и протокол кооператива3 не меняются. Старое уведомление о более высоком номере не сбрасывается: повторного сообщения об обновлении назад нет.

Работа продолжает пользовательский main b99ef4d. Сохранены компактные «Напитки»/«Прогресс», увеличенный Кнопик, покупка Хилки/Пепси/Живчика без рецепта, BULB только для рецептов, необязательные ставки ирокеза в играх на навык.

Активный баланс и AURA теперь в двух равных ячейках одной строки: одинаковые монеты, подписи, числа и отступы. Большие числа показаны полностью с уменьшением шрифта; ноль остаётся видимым. Сейф и обработчики денег не изменены.

Анонс полностью собран из нативных SVG игры, без генерации изображений: настоящие персонажи и одежда, бутылки, автомат, рулетка, карты и кости. Новая композиция — комната аркады с баром и игровыми столиками, крупным левым заголовком и билетом 0.3.0 справа. Оранжевые плоские цвета; персонажи размещены на разных планах. Дата16.10.26.

`npm run announcement:arcade` воспроизводит:

- `outputs/announcement/knopik-go-arcade-update-0.3.0-orange.png` —2160×2160;
- вариант `-1080.png` —1080×1080;
- исходный `.svg` и `public/release-artwork/orange-arcade-030.svg`.

Загрузка аккаунта и стартовое меню используют общий ReleasePoster и палитру текущей презентации. Реальные состояния загрузки/ошибок/установки/кооператива сохранены. Новый адрес SVG и content-addressed offline-pack доставляют новый арт независимо от номера0.3.0. Предыдущие SVG остаются архивными; Release CLI не выбирает retired-презентации для нового выпуска. Для следующего обновления сохраняется требование нового оригинального анонса и загрузки.

Проверка: нативный экспорт PNG просмотрен. Все43 обязательных тестовых файла Pages, TypeScript и ESLint прошли. Дополнительно проверены отказ Release CLI от архивных презентаций и сохранённая механика ставок ирокеза. SSR сохраняет полные числа вплоть до MAX_SAFE_INTEGER и нули; CSS разобран PostCSS. Сборка Pages успешна:77 файлов,13.9MiB; новый SVG есть в HTML и манифесте с правильным SHA-256. Браузер/физический телефон не проверялись.
