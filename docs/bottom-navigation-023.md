# Нижнее меню · 0.2.3

Магазин был полупрозрачной modal-backdrop над тапалкой. Его содержимое заканчивалось перед старым нижним меню, которое оставалось в исходной сцене с высоким z-index. Поэтому возле/под меню была видна затемнённая тапалка. Настройки рисовали отдельный footer в другом контейнере: ограничение ширины 560px против 500px у тапалки и независимые margin/padding давали другое положение.

Магазин перенесён в существующий GameModal (native dialog) как полноценный непрозрачный экран. Внутри shop-page-layout — прокручиваемое содержимое и отдельный BottomNavigation с активной первой вкладкой. Фон диалога и backdrop непрозрачны, заполняют весь viewport, включая пространство под меню. Базовое меню тапалки не рендерится при открытых магазине/настройках. Смена категорий, покупка/примерка, кейсы, возврат к Кнопику и переход к третьей вкладке используют существующие обработчики. Убрана лишняя вложенная role=dialog, Escape закрывает магазин.

app/bottom-navigation.css задаёт общие значения: высота72px, ширина min(viewport,500px) минус одинаковые боковые поля, нижний отступ10px + safe-area-inset-bottom. Боковые поля учитывают safe-area-inset-left/right. Тапалка резервирует отступ на уровне game-shell, магазин/настройки — на уровне одинаковой сетки страницы. У footer нет собственных дополнительных margin. Удалены конкурирующие ограничения/отступы из interface-polish.css и game-settings.css. Размеры кнопок перенесены без изменения, устаревший backdrop-filter у меню отключён.

Патч0.2.3 зарегистрирован командой release. Проверены JSX/TypeScript, ESLint, существующие обязательные35 файлов и Pages-сборка. CSS разобран PostCSS; отдельно просмотрен каскад правил геометрии bottom-bar, чтобы старые правила высоты/отступов не побеждали общий источник. Новые зеркальные тесты CSS не добавлялись. Браузерную URL-политику не обходили; реальный кадр/физический телефон в этом окружении не проверены.
