# Обводка, импульс урона и иконка · 0.5.0

Игровая рамка теперь использует фиксированный пиксельный tile48×48 вместо SVG без собственного размера в border-image. Tile запекается из SVG-мастера, inline CSS и master проверяются попиксельно. Процентные срезы25%, углы12px и размеры кнопок прежние. Непрозрачный тёмный внешний1px и светлый внутренний2px края образуют один непрерывный контур. Отдельный верхний слой без filter/backdrop-filter работает на всех пяти качествах; blur остаётся только у стекла high+. Это исключает зависимость контура от WebKit-композиции векторной рамки и размытия.

При настоящем уроне края экрана плавно краснеют и гаснут за1000мс. Центр остаётся прозрачным, ввод проходит насквозь. Один статичный radial-gradient и opacity-only CSS; нет дополнительного RAF, таймеров, scene filters или React state на каждом кадре. Повторный удар перезапускает импульс без чтения layout. При паузе/карте эффект очищается, после возвращения не проигрывается заново. Reduced motion уменьшает интенсивность.

Одиночная игра вызывает отдельный damage callback только после принятого урона, включая попадание перед восстановлением щитом. Coop проверяет локальное авторитетное здоровье: первый снимок только baseline, повторные/старые snapshots и ранения напарника не вызывают импульс. Run запускает эффект на collision hit, поглощение щитом не считается уроном. Сеть/урон/сохранения не меняются.

По последнему уточнению иконка остаётся GO: большие кремовые пиксельные буквы на ровном фирменном #8e473d. Рамка-кнопка, персонаж и оружие исключены. 5×7 glyphs нарисованы SVG-путями, шрифт/генерация фото не используются. Экспорт512/192/180 и отдельный maskable укладывается в гарантированную80%-диаметровую окружность. Metadata/manifest используют новые go-mark URLs; старые go-icon/go-512/go-192/go-apple-touch/go-cover тоже обновлены.

Скрипты: node scripts/build-control-frame.mjs и node scripts/build-go-app-icon.mjs. Проверки: весь набор115тестовых файлов, отдельные guards урона/кооператива, повтор импульса, CSS envelope, попиксельная рамка, размеры/непрозрачность и safe circle иконок; TypeScript/ESLint/production export. Нативные SVG-превью и HTTP-проверки не являются проверкой Safari/iPhone; браузерный запрет не обходился. Номер игры0.5.0, Save37 и Coop6 без изменений.
