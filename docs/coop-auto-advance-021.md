# Автоматическое продолжение кооператива · 0.2.1

После совместной победы через две секунды ведущий автоматически переключает ту же комнату на следующий уровень. Оба клиента получают новый round/seed, остаются в playing, новый уровень запускается без лобби и повторного подтверждения готовности. Номера аккаунтов, код комнаты, одежда и скины не меняются. Кампания 1–24 ведёт на следующий уровень, 25 — на первый этаж Бездны. Аркада/Бездна продолжаются в своём режиме до существующего предела 9999. После поражения автоматического перехода нет.

`CoopAutoAdvance` допускает только один запрос, удерживает короткий экран победы и откладывает продолжение при потере связи/скрытом устройстве или подтверждении выхода. На победе снимаются оставшаяся локальная пауза/карта: запоздалая пауза гостя не должна навсегда остановить переход. Повтор при ошибке имеет задержку; интерфейс показывает причину и кнопку повтора. Выбор другого маршрута и выход остаются доступны.

Новый `public.knopik_go_coop_advance(code,token,round)` — SECURITY INVOKER-обёртка. Проверки и изменение строки выполняет private-функция с фиксированным пустым search_path, существующей проверкой GO-доступа, auth.uid и токеном устройства ведущего. Строка блокируется FOR UPDATE; expected round позволяет повторить потерянный ответ без пропуска уровня. Следующий маршрут вычисляет сервер. Только этот RPC меняет одновременно level/mode/round/seed; промежуточной waiting-стадии нет. Гость, неправильный токен, закрытая комната, будущий/пустой номер, несовместимый протокол и пропавший напарник не могут запустить новый уровень. Личная экономика и сохранения не затрагиваются.

Команда проходит через прежнюю очередь CoopSession, чтобы старый heartbeat не откатил состояние. Broadcast room-updated ускоряет доставку; если он потерян, пакет состояния с большим round также инициирует обновление комнаты. Периодический heartbeat остаётся резервным путём восстановления. Основной протокол3 и локальная схема save33 прежние; новый клиент использует установленный серверный RPC.
