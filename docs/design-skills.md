# Скиллы дизайна Knopik GO

Набор установлен в `.agents/skills/` и хранится вместе с проектом. Он задаёт
инструменты для следующих задач; исходники интерфейса при установке не менялись.
В новой сессии Codex, открытой в корне этой копии проекта, доступны:

| Скилл | Роль |
| --- | --- |
| `knopik-ui` | Бриф Knopik: минимализм, яркие акценты, дружелюбный UI в духе Duolingo |
| `ui-ux-pro-max` | Локальная база UX, доступность, цвета, шрифты и React/Next.js |
| `frontend-design` | Композиция и реализация интерфейса в рамках нашего брифа |
| `webapp-testing` | Браузерные сценарии, скриншоты и проверка взаимодействия |

Для первого изменения можно написать:

> Используй $knopik-ui и $ui-ux-pro-max. Упрости главное меню: светлый фон,
> крупная яркая кнопка «Играть», понятный прогресс и минимум лишних деталей.
> Сохрани персонажей, сцены, экономику и сохранения. Проверь результат в браузере.

## Локальные инструменты

Из корня проекта (Python 3, без дополнительных библиотек для поиска):

```bash
python3 .agents/skills/ui-ux-pro-max/scripts/search.py "touch target spacing" --domain ux
python3 .agents/skills/ui-ux-pro-max/scripts/search.py "focus button" --stack react
python3 .agents/skills/webapp-testing/scripts/with_server.py --help
```

Для браузерных проверок отдельно требуется Python Playwright и установленный
браузер. Они не добавлены в зависимости игры. Долгоживущие соединения игры
могут мешать `networkidle`: проверяй готовность по конкретному элементу.

Из другой рабочей директории используй абсолютный путь к скрипту. Для поиска
не нужны ключ API, аккаунт Adobe, Figma или генератор изображений. Игровые
ассеты остаются SVG/CSS согласно правилам проекта.

## Источники и обновление

- UI/UX Pro Max: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill (MIT).
- Frontend Design и Webapp Testing: https://github.com/anthropics/skills (Apache-2.0).
- `knopik-ui` — собственная инструкция проекта по принятому брифу.

Точные commit SHA, исходные пути, изменения адаптации и SHA-256 всех включённых
сторонних файлов записаны в `.agents/skills/sources.lock.json`. Лицензии лежат
в соответствующих папках. UI/UX Pro Max включает runtime-скрипты, данные и
справочники; upstream-тесты установщика не включены. В его SKILL.md исправлены
пути Claude на локальную папку Codex. Ни npm-установщик, ни внешние API при
установке не запускались.

Обновляй набор явно: выбери новый upstream commit, просмотри изменения,
сохрани адаптацию путей и продуктовый бриф, обнови контрольные суммы, затем
проверь поиск и `with_server.py --help`. Базу рекомендаций не следует
автоматически считать новой дизайн-системой игры.
