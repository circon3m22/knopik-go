# ПК: весь экран — 0.7.1

Исправление неудачной адаптации 0.7.0 по замечанию пользователя «плохо везде».

- Определение ПК по `any-hover` + `any-pointer`, независимо от ширины окна. Узкое окно и масштабирование Windows больше не включают сенсорный контроллер и не скрывают Ultra.
- Устранена настоящая причина сжатой главной: старый `.game-shell` продолжал ограничивать всю новую сетку шириной 500 px. Теперь оболочка занимает окно, слева — прогресс, предметы и навигация, справа — Кнопик и балансы.
- Сцены квартиры, подвала, кампаний, района и коопа занимают весь viewport. HUD, оружие и контекстное действие находятся поверх сцены; мобильные ряды не занимают высоту. Подробные клавиши открываются по F1.
- Меню семи зон: иллюстрация и описание слева, пять уровней справа. Карта: большая схема и отдельная боковая панель. Горизонтальные страницы магазина, настроек, бара, арсенала, коопа, каталога и всех семейств мини-игр используют реальные внутренние контейнеры.
- Камеры сохраняют равномерный масштаб и соответствие мыши сцене при смене размеров, включая окна меньше 960 px. Пересоздание после смены reduced motion/графики сохраняет desktop. Run также заполняет небольшое ПК-окно.
- M открывает и закрывает карту района и коопа. Выбор оружия мышью и WASD возвращают фокус полю; пробел после этого выполняет кувырок. Текст Run показывает клавиши ПК.
- По дополнительному запросу Кнопик смотрит по направлению движения во всех восьми направлениях. Кувырок использует уже выбранное направление переката. Оружие сохраняет независимый прицел мыши. Кооп выводит направление из уже передаваемого input; формат wire/save прежний.

35 кампаний, прогресс, экономика, доступ к аккаунтам и пиксельный круглый Верити сохранены. Заставка использует прежний пиксельный арт 0.7.0 с новой компоновкой ПК.

Проверки: новые интеграционные проверки камер после последовательных resize, проекции мыши, Run/района и направления тела/выстрелов обоих игроков. Статический аудит приоритетов всех 57 импортированных CSS для 1366×768, 1920×1080, 3440×1440, 800×600, 600×800 и сенсорного 390×844: `work/desktop-071-cascade.json`. Это анализ CSS, не измерение браузерной геометрии.

Native SVG сцены проверен в `outputs/pc-current-ultra.png`. Браузерная компоновка не подтверждена: существующее окно Chrome оказалось свёрнуто и инструмент не смог получить его состояние; запуск установленной игры также не дал управляемого окна. Запрет обхода localhost не обходился. Native PNG не является браузерным снимком или измерением FPS.

Итоговая проверка 2026-11-06: 767/767 тестов, TypeScript и ESLint изменённых компонентов прошли. Production `.next-pc-release071` и Pages `.next-pc-pages071` собраны. Все 100 файлов офлайн-пакета `805b49bdd65499af238d` проверены по размеру и SHA256.
