# Справочник: полевые заметки / 0.5.0

Причина сломанной вёрстки — активные правила старого `details.hunter-bestiary`. Селектор `.hunter-bestiary>div` делил вступление на две колонки, `.hunter-bestiary article` выигрывал по специфичности и задавал колонку портрета 38px. Эти правила и старый CSS-класс удалены.

Карточки сахуров теперь имеют отдельную строку портрета/названия, полноширинное описание и отделённую тактику. Портрет квадратный, с областью, которая вмещает широкий атлас стрелка. Список в одну колонку, ширина чтения ограничена 600px; на узких экранах уменьшается только строка портрета. Текст не имеет фиксированной высоты и может переноситься. Есть общий счётчик и восемь полосок открытий, без имён/портретов неизвестных врагов.

Оружие использует тот же ритм карточек: рисунок, название, отдельные значения урона/интервала с действующими улучшениями, три индикатора ступеней. Закрытое оружие не раскрывается. Правила — семь отдельных нумерованных заметок.

Внутри справочника скрыт дублирующий ряд «Аркада / Справочник». Три кнопки разделов и возврат к зонам доступны отдельно от прокручиваемого содержимого. Новый раздел получает новый контейнер прокрутки и начинается сверху. Кнопки связаны с областью содержимого через aria-controls/aria-labelledby.

Проверки: старые тесты журнала/экономики, новые регрессии структуры всех восьми карточек, отсутствия старых CSS-правил, значений улучшенного оружия, навигационных связей; ESLint, TypeScript и статическая сборка. `outputs/guide/portraits.png` — нативная SVG-проверка портретов через Sharp с атласами, преобразованными в PNG для librsvg. Это не браузерный снимок и не проверка Safari/iPhone. Браузерный URL-запрет не обходился.

Версия 0.5.0, Save37, Coop6, мир, управление, сохранения и экономика не меняются.
