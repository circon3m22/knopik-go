# Полировка интерфейсов и миров 0.5.0 · 18.10.2026

Последнее уточнение пользователя: сверху нужен один компактный непрозрачный контур, снизу — только отдельные кнопки. Без blur на всех качествах. Общий нижний док тапалки остаётся прежним. Версия игры, Save 36, Coop 5, загрузка, обложки, цены, покупки и серверные данные не меняются.

## Интерфейс и граница игрового поля

- `gameplay-controls.css` отключает мировой backdrop-filter, сохраняет непрозрачные заливки отдельных кнопок, выделенное оружие и цвета действий.
- `gameplay-inset-hud.css` задаёт один непрозрачный верхний контур с отступами, без отдельных фонов у жизней, баланса и трёх кнопок. У нижнего контейнера отсутствуют фон, видимая граница и тень.
- Прежний SVG clip среднего ряда оставлял сплошной фон диалога под контроллером. Теперь за пределы измеряемого viewport выходит только отрисовка SVG; общий layout обрезает её по краям. Формулы камеры, resize, joystick, нижняя сетка и touch targets не менялись.
- CSS lighting и vignette покрывают весь layout, включая мир под контроллером. Раньше постобработка заканчивалась у нижней границы viewport, создавая разницу в яркости. Viewport больше не создаёт отдельный stacking context: scene z0, единая постобработка z1, HUD/контроллер/toolbelt z5, диалоги z10+. Low/medium без постобработки. Те же правила применены к улице и кооперативу.

## Тапалка и фоны

- Верхние действия сведены в одну строку: логотип, Напитки, Прогресс с уровнем/наградой, выход/аккаунт. Ниже — четыре карточки предметов с внутренним разделителем между применением и покупкой. Убран лишний промежуточный ряд.
- Сохранены круг32, неподвижная маска анимации, размер портрета, центрированные активный баланс и аура, сейф, сплошной нижний док и завершённый onClick навигации.
- Восемь разных сцен пересобраны на сетке160×320: тёплая комната, облачная терраса, хамам, лунный город с водой, кедровая баня, кристальная пещера, панорамный пентхаус, латунная обсерватория. Первоначальные названия/ID/цены прежние.
- Материалы high+ содержат отдельную кладку, древесные штрихи, мозаику, окна/отражения и астрономические детали. Повторяющиеся элементы объединены в paths. Все сцены без растров, blur, SVG filters и градиентов.
- Всего path/rect узлов восьми фонов: low97, medium130, high166, very-high182, ultra190. До этой правки:112/172/392/641/785. Более длинные составные paths сохраняют дополнительную геометрию при меньшем DOM. Поэтому проверка детализации считает контуры, а не требует удваивать число DOM-узлов.
- Сохранены малые CSS-анимации, статичные превью, reduced motion, остановка при скрытой вкладке и закрывающих игру экранах.

- Двери, мебельные коллайдеры, проходы, компьютер, лаборатория, бар и сейф остаются на рабочих местах. Орнамент не создаёт невидимых препятствий.

## Уровни и движок

- Обычный input pilot прошёл35уровней с реальными целями, боями и расходниками. Пространственные проверки охватывают комнаты, проходы, укрытия, задания, сундуки, подъёмники и спавны. Блокировок прохождения в этих сценариях не найдено.
- Найдены выходящие за внутреннюю ширину табличек подписи первого уровня:280.5 и282.6 при доступных260ед. на17pxTiny5. Карта ранее могла обрезать длинные названия многоточием.
- `pixel-text-layout.ts` использует advances Tiny5, учитывает широкие кириллические буквы и переносит полное название в ограниченную область. Таблички и подписи карты теперь учитывают ширину и высоту. У табличек fontSize задан inline, поскольку общий CSS раньше перезаписывал SVG presentation attribute.
- `AdventureEngine.notify` сравнивает значения view напрямую вместо JSON.stringify всего объекта на каждом шаге. `visited` остаётся копией, предыдущий снимок не меняется задним числом.
- Счётчики врагов вычисляются одним циклом без временных filter-массивов; gateOpen проверяет зависимости без slice-массивов. Бой, управление, награды и порядок UI-уведомлений сохранены.

## Измерения и проверка

Парное чередование исходного e704fb2 и новой реализации в Node:120прогревочных+1080измеряемых кадров для каждого варианта и сцены. Медианное время шага движка уменьшилось на25.7%/20.2%/28.3%/26.9% для уровней1/15/25/35medium, на22.5% для35ultra, на31.9% для квартиры medium. Это время JavaScript движка в тестовом окружении, не FPS телефона. Перерисовка динамических SVG сохранила прежние пулы и количество изменений DOM; сравнение движения/врагов/view/порядка уведомлений на25200парных кадрах всех35уровней совпало.

Проверки:105тестовых файлов без ошибок; TypeScript и ESLint изменённых модулей; Pages production build. Дополнительно160реальных SSR-состояний меню (8тем×5качеств×2экрана×2контекста входа),40SVG фонов, четыре нативных кадра новых гостиных и20проверок SVG paint за пределами viewport. Камеры при движении вниз/стрельбе сравниваются на пяти качествах и трёх размерах экрана. Нативные SVG-превью и SSR не являются браузерными скриншотами; Safari/iPhone FPS не измерялся. Браузерная URL-политика не обходилась; полный игровой прогон Run через аккаунт не выполнялся.

Артефакты проверки находятся в игнорируемых `outputs/refinement`, `outputs/tap-menu`, `outputs/tap-backgrounds`, `outputs/menu-readability`, `outputs/world-bleed` и `outputs/performance/refinement-profile.json`.
