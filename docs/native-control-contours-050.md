# Нативный контур управления · 0.5.0

Пользователь повторно сообщил об отсутствии рамки на очень высокой/ультра графике после публикации варианта PNG border-image. Самостоятельная проверка на Safari/iPhone недоступна. В этой правке механизм border-image удалён целиком: контур больше не зависит от декодирования фонового изображения или отрисовки CSS border-image рядом с backdrop-filter.

GameControlRim стоит прямо внутри button, отдельно от GameControlSurface. Контур z3, содержимое z2, стекло и meter внутри surfacez0. Четыре12pxугла — нативные SVG пути из прежнего master; прямые участки — обычные CSS border1pxтёмный/2pxсветлый. Grid12px/minmax(0,1fr)/12px сохраняет рисунок на широких и квадратных кнопках. Corner SVG имеют собственные width/height!important, так что стили размеров оружия/атаки не уменьшают их. Ни border-image, ни растровый tile, ни mask не используются.

На high/very-high/ultra только сам контур получает translateZ(0), отдельный слой композиции над стеклом. Предка backdrop не промотируем. Рамка не зависит от качества, не тускнеет на disabled, не имеет filter/backdrop-filter и не перехватывает ввод. visibility наследуется от кнопки: при паузе/карте скрывается весь chrome, включая рамки.

Повторное построение master: node scripts/build-control-frame.mjs генерирует app/game-control-frame.ts из public/ui/game-control-frame.svg. Проверки: структура прямого потомка, исключение из disabled fade, все5качеств, отдельное продвижение верхнего слоя, четыреSVGугла и четыре CSS границы; Sharp проверяет непрерывность/пустой центр на48×48,42×44,207×40,147×147,90×30. На48×48 результат попиксельно совпадает с master. Это проверка рисунка/структуры, не скриншот реального WebKit.
