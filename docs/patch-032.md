# Knopik GO — 0.3.2

Дата: 16 октября 2026.

- Напитки и Прогресс расположены в одной строке в режиме компьютера; общий пиксельный стиль, 46 px кнопки.
- Увеличена зона Кнопика до размеров доступного dog-orbit.
- Хилка, Пепси, Живчик доступны для покупки сразу, без первого приготовления; остальные напитки требуют рецепт. Лимиты прежние.
- BULB — общий чит-код: открывает все рецепты, без начисления напитков или ресурсов; безопасен при повторном вводе.
- Новый квадратный SVG-арт на стартовом меню. PNG не экспортирован в GitHub в рамках этой операции.
- Обновлены тесты логики; проверка на реальном устройстве остаётся необходимой.
