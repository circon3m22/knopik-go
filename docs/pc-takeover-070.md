# PC TAKEOVER 0.7.0 — 2026-11-06

The update is based on public main `29bc235`, preserving all 35 Expedition campaigns, seven zones, the expanded neighborhood, eight homes, progression, weapons and saves. The earlier local Adventure v20 was stale; its intermediate PC implementation was backed up under `work/pc-legacy-backup` and was not published over newer work.

PC layout activates at 960 CSS pixels with a fine pointer and hover. World cameras fill the measured horizontal viewport with a uniform scale. Adventure, the neighborhood and co-op use the existing world projection, collision, culling and fixed simulation clock. Run extends its sky, skyline and ground to the wider camera. Tapper, settings, shop, arcade library and game panels gain wider layouts. Touch layouts retain their joystick and action buttons.

WASD/arrows move, mouse aims, LMB/J attacks, Space rolls, E interacts, M opens the map, 1–8 selects unlocked weapons, H heals, L arms the shield, F uses surge and Q activates the cape. Run uses W/up to jump and Space/S/down to roll. Native keyboard activation remains available in menus. Mouse release, cancellation, lost focus and modal transitions clear held input. Clicking a visible enemy body aims at its actual floor collision position. Co-op carries an optional finite aim angle in the existing input message, independently for each player; existing controls without this field remain valid. No backend or access policies were changed.

Ultra is an additional PC-only option alongside the existing three presets. It selects the existing highest lighting pipeline and adds pooled combat sparks, expanding shock rings and sabre traces. Capability and the local PC preference gate the extra SVG nodes; low/medium and touch do not mount this pool. The existing physics clock advances effects, reduced motion disables the extra animation, and paused clocks remain frozen. Lighting, haze, reflections and occlusion use the current source-bound renderer. The [PixelFX](https://github.com/patch-gg/pixelfx) library informed the timing and layered-effect approach; no third-party source or dependency was copied.

Each of the 35 campaigns appends two Verities after the existing Sahurs, preserving existing enemy IDs and reinforcement triggers. Actor counts remain at most 36. Spawns avoid covers, hazards, tasks and other enemies. Verity is a round floating 32×32 pixel sphere with quantized gold shading, stepped oval eyes and a stepped smile, based on ThatMob's character. Every live pose uses the same circular geometry. Rolls rotate and translate the sphere without an anisotropic scale. Separate idle, windup, roll, glitch and recovery poses use the existing renderer. Side rolls obey the ordinary collision substeps, have a cooldown and can be interrupted by damage. Generated arcade and Abyss layouts retain their existing enemy roster.

Verification includes TypeScript, ESLint, campaign input pilots, camera unprojection, manual/automatic aim separation, two-player aim isolation, reachable spawns, pause/collision/recovery, circular roll poses, fixed node/effect budgets and release artwork checks. Native preview files are `outputs/pc-current-ultra.png`, `outputs/verity-round-roll.png` and `outputs/announcement/pc-takeover-070*.png`. They are isolated SVG renders, not browser screenshots or phone FPS measurements. The existing browser URL restriction was respected.

The new square/portrait release artwork uses the established 360-pixel integer grid. Save 38 and coop wire 7 remain compatible; the service worker/offline pack is rebuilt from the final Pages export.

The final artwork revision replaces the initially rejected simple cover with a detailed industrial action scene. It bakes the existing articulated Knopik and the actual pixel Verity into integer SVG runs using the same native export method as the Expedition cover. No smooth gradients or curves are used for Verity.

Final validation: 763 general tests passed; the final pixel artwork revision passed 38 targeted tests. TypeScript, app ESLint, production and Pages builds passed. All 100 assets in offline pack `96aef432743bb2c9f119` matched their SHA-256 entries. The sandbox production session reported Ready for `.next-pc-release070` on port 3002; a host HTTP probe timed out, so a host-accessible local preview is not confirmed.
